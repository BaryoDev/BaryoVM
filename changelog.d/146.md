**`vm patch <name>`.** Updates OS packages on a VM as a detached systemd unit, decides the reboot from the host (`needs-restarting -r` or `/var/run/reboot-required`), reboots only with `--reboot` or a prompt, then checks every container, nginx and `nginx -t` against a snapshot taken first. A container that was already unhealthy is not a failure; one that does not return makes the command exit non-zero and names it. `--dry-run` lists pending updates. ([#146])
