- **`baryovm repo init <owner/repo> --template <name>` scaffolds release CI, and `baryovm repo verify <owner/repo>` checks that trusted publishing works.** `init` writes the workflows and furniture (CODEOWNERS, issue templates, CONTRIBUTING) into a local checkout, applies branch protection with the required checks through the GitHub API, and prints the owner, repository, workflow file and environment to enter on nuget.org or npmjs.com. It prints a plan and does nothing without `--yes`, and never overwrites a file without `--force`. It does not create the registry policy, which has no API on either registry; the output spells out the order (push the workflow, create the policy by hand, then verify). `verify` runs the workflow's dry run and reports whether the OIDC exchange step succeeded. Two templates are built in, `dotnet-nuget` and `node-npm`, based on the umbraco-pwa and dopaminejs workflows, with every action pinned to a commit sha. `--templates-dir` adds or replaces templates. The token comes from `--token-ref`, `GITHUB_TOKEN`, `GH_TOKEN` or `gh auth token`. ([#52])
