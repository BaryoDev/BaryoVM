- **Passive edge checks in `scan`, and `--resolver`.** After the ZAP baseline, `scan` checks CAA, SPF, DMARC, whether the bare IP serves a site over HTTPS (no SNI) or HTTP, `security.txt` per RFC 9116, and reports the HSTS header as a value. Findings join the ZAP findings in one list with the same severities, `--fail-on` and `-o json` envelope; edge findings add `check` and `detail`. It sends five DNS lookups and three HTTP requests, each with a timeout inside a 30 second cap. `--resolver <ip[:port]>` pins the DNS server. `--url` now refuses a bare IP, a non-punycode name and a URL with credentials.
