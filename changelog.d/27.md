- **`baryovm status`.** One read-only screen for every registered stack: whether its containers are up, the commit of the last finished release, a release that failed or stopped part way, the verify assertions run now, and the backups on the VM. Each VM is asked once over one SSH connection, VMs are queried concurrently (`--concurrency`) with a per-VM `--timeout`, and a VM that does not answer shows as unreachable with the reason while the other rows still print. A column that is not configured shows `-`, one that could not be read shows `?` with the reason. A forced-command VM is sent its `status` request only and shows as limited. `-o json` carries the same report. `--vm` and `--stack` scope it. ([#27])
