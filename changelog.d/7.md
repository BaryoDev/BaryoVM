- **Adopt a hand-run container.** `stack release --adopt` and `stack deploy --adopt` remove a hand-run container that holds a `container_name` the compose file wants, after printing its name, image and created time. If it uses a named volume the compose file does not declare `external: true`, the adoption is refused, nothing is removed, and the volume name and the YAML to add are printed. There is no bypass flag. ([#7])
