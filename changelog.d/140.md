- **`baryovm git` and `baryovm gh` refuse keys and pushes to the wrong host.** `git commit` scans the staged diff (and the working diff with `-a` or paths) and the message; `git push` checks the remote host against `baryovm.allowedHosts` in git config (or `BARYOVM_ALLOWED_HOSTS`) before any network call, then scans every commit not on the remote. `gh pr create`, `gh release create` and `gh issue create` scan `--title`, `--body`, `--body-file`, `--notes` and `--notes-file`. A refusal names file and line, never the value, and exits 1. Everything else passes through with the tool's own output and exit code. `guard install-hooks` writes pre-commit and pre-push hooks that run the same checks. ([#140])
