- **`--dry-run` on `stack release`, `stack deploy`, `stack backup`, `stack restore`, `vm bootstrap` and `deploy`.** Each prints the commands it would run and opens no connection. `stack release --dry-run` shows the rsync invocations (with `--delete` and the trailing slash), builds, hooks, backup and compose up, and never runs a hook, takes the release lock or writes a record. `stack restore --dry-run` needs no `--yes` and names the backup it would use. In `-o json` the plan is in `data`. ([#34])
