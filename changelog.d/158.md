- **A release manifest's `localRoot` and `sync` paths are confined to its directory.** Each must resolve, after symlinks, inside the folder holding the manifest, so a manifest from another branch can no longer name `~` and `.ssh` and copy a private key to the VM. Refused at load (so `--dry-run` refuses too), and a `sync` entry that is a symlink pointing out is refused before rsync runs. A manifest that has to sit apart from its source needs `baryovm stack add --release-root <dir>`, set once by the operator and stored on the stack. A manifest or project file cannot set it. The rsync trailing-slash rule is unchanged. (#158)
