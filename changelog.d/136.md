- **`stack release` records its progress and can resume.** A JSON file on the host, written under the host lock before the first step that changes anything, holds the commit, the backup taken, the steps done and the failed step with its error. A finished release removes it and records the deployed commit. A release that finds one refuses and says what the earlier run did and did not touch. `--resume` continues from the first step not done with the same backup, and `--clear` removes the record. A half-applied deploy is not resumable and points at `stack restore`. ([#136])
